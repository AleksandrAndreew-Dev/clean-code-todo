# Инструкция для AI-ревьюера

## 1. Цель

Проведи статический анализ файла `app.js` из проекта Todo App. Найди нарушения принципов Clean Code.

## 2. Границы

- Проверяй только файл `app.js`.
- Не изменяй файлы в проекте. Только анализируй текст и выдавай текстовый ответ.
- Ищи проблемы в категориях: мёртвый код, дублирование, нечитаемые имена, комментарии-пересказы, большие функции.

## 3. Критерий готовности

Ревью считается завершенным, когда ты выдал полный список найденных проблем с объяснениями.

## 4. Формат вывода

Выдай отчет на русском языке. Каждое замечание оформляй по следующему шаблону:

- **Место в коде:** [номер строки или название функции]
- **Проблема:** [описание проблемы]
- **Условие проявления:** [при каких условиях это станет проблемой]
- **Способ проверки:** [как разработчику убедиться, что проблема исправлена]
